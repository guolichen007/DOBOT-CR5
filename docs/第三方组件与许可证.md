# 第三方组件与许可证

本目录以 bundled/vendor 或系统依赖方式使用以下第三方组件。

## 系统依赖 (ROS / apt)

| 组件 | 许可证 | 备注 |
|------|--------|------|
| ROS Noetic | BSD | 机器人操作系统 |
| Gazebo Classic 11 | Apache 2.0 | 仿真引擎 |
| MoveIt | BSD | 运动规划框架 |
| OpenCV 4.2 | Apache 2.0 | 计算机视觉 |
| Ceres Solver | BSD | 非线性优化 |
| Open3D | MIT | 三维重建 |
| nlohmann/json | MIT | JSON 解析 |
| PCL | BSD | 点云处理 |

## Vendor / Bundled

| 组件 | 位置 | 许可证 | 备注 |
|------|------|--------|------|
| DOBOT CR5 驱动 | `src/dobot_bringup/` | DOBOT_VENDOR_LICENSE | CR5 机械臂 API |
| RealSense Gazebo | `src/realsense_gazebo_*/` | Apache 2.0 | D455 仿真 |

## 说明

- 所有 bundled 组件的许可证以各目录内 LICENSE 文件为准
- 本表格仅供参考，不构成法律建议
- 第三方依赖的完整许可证文本见各 package 的 package.xml 和源文件头
