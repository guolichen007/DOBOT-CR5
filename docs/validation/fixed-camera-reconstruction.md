# 固定三相机工作空间重建验证

日期: 2026-08-05

## 验证目的

八姿态鲁棒性验证发现，TSDF 重建结果中包含两类非目标几何：
1. 后置相机支架/横臂（固定场景结构）
2. 悬挂钢筋/吊杆（与工件一起移动的吊具）

这些结构不属于待重建工件，但被送入 TSDF 并被 mesh cleanup 保留（因为"有真实深度支持"）。

目标隔离在 TSDF 前排除已知非目标结构，将输出从"目标主体 + 少量吊具/支架残留"收敛为"仅目标主体的可见表面"。

## 固定条件

- 三台相机外参：隔离前基准外参，未修改
- 三台相机位置：未修改
- TSDF voxel=0.005 / trunc=0.020：未修改
- mesh cleanup 保守策略：未修改（仅增加已知非目标分量删除）
- 隔离前基准配置：全部冻结参数保持不变

## 八姿态定义

验证覆盖八种工件姿态（P0-P5, E1, E2），包含不同平移量和旋转角度组合，覆盖已验证工作包络及边界条件。

## 目标隔离方法

目标隔离在 TSDF 融合前执行，由三层过滤组成：

1. **静态 AABB 排除**：基于已知非目标结构的空间包围盒，剔除固定场景元素
2. **世界高度天花板**：排除场景中高于工件范围的悬挂结构
3. **细长分量分类**：在 mesh cleanup 阶段，将连通分量按几何特征分类为后置相机支架（REAR_CAMERA_PEDESTAL）或悬挂钢筋（SUSPENSION_ROD），对已知非目标分量强制执行删除

## 悬挂钢筋分类

mesh cleanup 阶段对连通分量进行几何分类。识别为悬挂钢筋（SUSPENSION_ROD）的分量具有细长几何特征（对应与工件一起移动的吊具/吊杆），在最终网格中强制删除，与静态 AABB 排除互补，共同消除非目标几何残留。

## 工程权衡

### P1/P4 Completeness 回归（已知工程权衡）

目标隔离删除了经 visible GT 距离验证的非目标静态支架点。

由于 TSDF 融合对输入深度集合存在边界敏感性，P1/P4 的 Completeness coverage@10mm 相对隔离前基准分别下降 0.008 和 0.009。

该变化未由目标表面误删引起：
- 被排除点距 visible GT 均超过 118mm；
- 收窄静态排除区域后，被排除点集合保持不变；
- Accuracy median 基本不变，Accuracy P95 略有改善。

项目接受该确定性工程权衡，以换取最终网格中已知非目标支架和悬挂杆残留的清除。

原质量 Gate 与阈值保持不变。此回归记录为一次经过审查的例外，不等同于放宽回归约束。
