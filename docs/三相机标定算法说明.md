# 三相机标定算法说明 (Stable V1)

本文档描述 CR5 三相机联合标定的完整算法流程, 以当前 Stable V1 代码实际实现为准。

## 1. 系统目的

通过多姿态标定靶观测, 计算三台固定 RGB-D 相机之间的精确外参 (T_rig_camera),
为后续三维重建和喷涂路径规划提供相机间空间关系。

## 2. 坐标系

```
world (Gazebo) 或任意固定参考系
  └── cam_front_left_color_optical_frame   ← rig 基准 (gauge)
  ├── cam_front_right_color_optical_frame  ← 相对于 FL
  └── cam_rear_color_optical_frame         ← 相对于 FL
```

- 前左相机 (FL) 固定为 identity, 作为 rig 坐标原点
- FR 和 RE 的外参定义为 T_FL_FR 和 T_FL_RE (从 FL 光心到目标相机光心的 SE(3) 变换)
- 光学坐标系定义: +Z 向前 (拍摄方向), +X 向右, -Y 向下 (ROS standard)

## 3. 三台相机角色

| 相机 | 名称 | 角色 |
|------|------|------|
| 前左 | cam_front_left | rig gauge (固定 I) |
| 前右 | cam_front_right | 自由估计 |
| 后 | cam_rear | 自由估计 |

## 4. 标定靶

五面板标定目标, 面板贴在长方体主体外围。

主体尺寸: 0.34 × 0.28 × 0.24 m (X × Y × Z, 以靶心为原点)

| 面 | 朝向 | 图案 | ID 范围 | 面板尺寸 |
|----|------|------|---------|----------|
| 前 | +X | ChArUco 8×6 | 100–123 | 0.24 × 0.18 m |
| 左 | +Y | AprilTag 2×2 | 4–7 | 0.22 × 0.18 m |
| 右 | -Y | ArUco 2×2 | 10–13 | 0.22 × 0.18 m |
| 顶 | +Z | AprilTag 单 | 8 | 0.16 × 0.16 m |
| 后 | -X | ChArUco 8×6 | 300–323 | 0.24 × 0.18 m |

> `calibration_target.yaml` 是标定靶几何的唯一权威来源。

## 5. 同步采集

三台相机通过 `joint_capture_manager` 进行跨相机同步采集。
使用 `message_filters.ApproximateTimeSynchronizer` 确保三帧时间戳偏差 ≤ 30ms。
实际 Gazebo 测量: 典型 4-8ms。

## 6. 图案检测

对每帧图像运行 `target_detector`:

- ChArUco (前/后面板): OpenCV `aruco.detectMarkers` + `interpolateCornersCharuco`, 角点精修 NONE (避免 ArUco 边缘尺度膨胀)
- ArUco (右面板): OpenCV `aruco.detectMarkers`, 角点精修 NONE
- AprilTag (左/顶面板): `apriltag` 库检测

DetectorProfiles 参数: 前后面板 refinement=1, 左右顶面板 refinement=0/1。

## 7. 单相机 PnP

每台相机对每个有效姿态独立运行 `solve_pnp`:

- 输入: 靶面坐标系下的 3D 点 + 对应图像 2D 点
- 自动检测共面/非共面, 选择 planar/nonplanar 分支
- 输出: T_camera_target (4×4 SE(3))

## 8. 成对相机相对变换

如果某组姿态下两台相机均有有效 PnP 解:

```
T_camA_camB = T_camA_target @ inv(T_camB_target)
```

三对相机均计算: FL_FR, FL_RE, FR_RE。

## 9. RANSAC 鲁棒共识

对每一对相机收集的所有 SE(3) 估计:

- RANSAC 种子: 依次尝试每个候选作为种子
- 内点阈值: 平移 50mm, 旋转 5°
- 选取最大共识簇作为内点集
- 共识不足 (内点 < 总数的 1/3): 标记为不可靠

## 10. 内点等权 SE(3) 平均

对内点集中的所有 SE(3) 变换:

- 使用迭代 log/exp 方法计算 SE(3) 均值
- 所有内点等权重 (不做 measurement quality weighting)
- 初值: 加权平移平均 + 四元数平均

## 11. FL Gauge

FL 固定为单位矩阵。FR 和 RE 的外参由对应成对变换的内点均值直接给出。

## 12. 三角形闭合

```
T_FL_FR @ T_FR_RE 应与 T_FL_RE 一致
```

闭合偏差反映三相机标定内部一致性, 不依赖外部真值。

## 13. 可靠性失败条件

标定输出 `CALIBRATION_NOT_RELIABLE` 当以下任一条件满足:

- 有效组数 < 5
- 某对相机的内点数 < 3
- 某相机外参缺失
- 外参矩阵含非有限值
- 旋转矩阵 det 偏离 1.0 超过 0.01

## 14. 外参输出

JSON 格式:

```json
{
  "solver": "pairwise_camera_relative",
  "version": "stable-v1",
  "cameras": {
    "cam_front_left":  [[1,0,0,0],...],
    "cam_front_right": [[R,t],...],
    "cam_rear":         [[R,t],...]
  },
  "pair_stats": {...},
  "triangle_closure_t_mm": ...,
  "status": "CALIBRATION_SUCCESS"
}
```

## 15. Gazebo 稳定版 V1 验证结果

场景: 三相机稳定仿真工位, 20 组固定相对姿态。

| 相机 | 平移误差 | 旋转误差 | 判定 (≤15mm / ≤1°) |
|------|---------|---------|-------------------|
| FR | 14.78mm | 0.680° | PASS |
| RE | 11.04mm | 0.816° | PASS |

三角形闭合: 4.5mm / 0.34°

## 16. 实机注意事项

- 每台 D455 需独立标定 K 矩阵和畸变系数 D
- 当前 CLI 支持 `--camera-k` 作为 fallback, 实机应从 CameraInfo topic 或文件读取每台相机独立参数
- 标定靶需按 `calibration_target.yaml` 尺寸实际制作
- 实机精度待三台 D455 安装后首次验证

## 17. 已知限制

- 单面 planar PnP 可能产生深度模糊 (已通过 RANSAC 共识和多姿态缓解)
- 当前求解器使用内点等权平均 (非 measurement quality weighted)
- Gazebo 15mm 基线不代表实机 D455 必然更差或更好
- Joint BA 不再作为最终外参求解器 (已在研发阶段证明 camera-target 联合补偿有害)
