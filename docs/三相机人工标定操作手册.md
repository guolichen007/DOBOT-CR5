# 三相机人工标定操作手册

本文档描述如何在 Gazebo 仿真环境中手动完成三相机联合标定的完整流程。

## 0. 标定目的

通过多个不同姿态下的标定目标观测，计算三台固定相机之间的精确外参（T_rig_camera），输出 schema v2 格式的 `initial_extrinsics.yaml`。

## 1. 环境准备

```bash
cd ~/cr5_ros1_ws
source devel/setup.bash
```

## 2. 启动 Gazebo 仿真

```bash
bash src/cr5_spray_sim/scripts/run_simulation.sh \
  --gui --object=calibration_target --profile=quality
```

等待所有信号就绪：CAMERA_COLOR_3_OF_3_PASS, CAMERA_DEPTH_3_OF_3_PASS, CAMERA_TF_OK

## 3. 查看三台 RGB 相机

```bash
source /tmp/cr5_spray_simulation.env

# 逐个检查
rqt_image_view /cam_front_left/camera/color/image_raw
rqt_image_view /cam_front_right/camera/color/image_raw
rqt_image_view /cam_rear/camera/color/image_raw
```

确认每台相机画面中有标定目标。

## 4. 检查 CameraInfo

```bash
rostopic echo -n1 /cam_front_left/camera/color/camera_info | grep -E "K|D|width|height"
```

三台相机应输出: K=[462.1, 0, 320, 0, 462.1, 240, ...], D=[], 640×480

## 5. 启动标定采集服务

```bash
roslaunch cr5_spray_perception calibration_pipeline.launch
```

确认服务可用:
```bash
rosservice list | grep joint_capture_manager
```

## 6. 单次同步采集

```bash
rosservice call /joint_capture_manager/capture_sync_group "{}"
```

预期: `success: True`, `SYNC_GROUP_3_OF_3_PASS`

## 7. 检查采集质量

```bash
GROUP_DIR=/path/from/response
cat $GROUP_DIR/group_manifest.json
```

关键指标:
- `captured: 3`, `expected: 3`, `success: true`
- `method: exact_stamp_ns`
- `max_inter_camera_skew_s <= 0.005` (≤ 5ms)
- 每台相机 `valid_depth_ratio >= 0.3`

人工核验 manifest 中三个 stamp 与三台 quality.yaml 中的 color stamp 一致。

## 8. 5 次同步稳定性测试

重复执行 capture_sync_group 至少 5 次。

全部 PASS 才能继续。

## 9. 标定目标检测

### 查看检测状态

右面 ArUco (ID 10-13): DICT_4X4_50, 4 个 marker, 16 个角点
左面 AprilTag (ID 4-7): DICT_APRILTAG_36h11, 4 个 tag, 16 个角点
前面 ChArUco (ID 100-123): DICT_5X5_1000, 最多 35 个角点

运行诊断:
```bash
rosrun cr5_spray_sim diagnose_calibration_visibility.py --output /tmp/vis
```

### 判断标准

| 状态 | 条件 | 处理 |
|------|------|------|
| GOOD | ≥ 8 points, PnP RMSE ≤ 1.5px | 接受 |
| WEAK | 4-7 points 或 RMSE 1.5-2.5px | 可接受（标注） |
| REJECT | < 4 points 或 RMSE > 3px | 调整姿态 |

## 10. 改变目标姿态

```bash
rosrun cr5_spray_sim set_calibration_target_pose.py --list
rosrun cr5_spray_sim set_calibration_target_pose.py --pose down
```

预定义姿态: center, left, right, up, down, yaw_p10, yaw_m10, pitch_p8, pitch_m8, combo_lu, combo_rd

## 11. 多姿态采集循环

对于每个姿态:
1. SET POSE → 等待稳定
2. LOOK → 肉眼检查画面
3. DETECT → 确认 marker 检测
4. CAPTURE → 调用 capture_sync_group
5. CHECK → 检查 manifest 和 detection
6. ACCEPT / REJECT → 决定是否保留

**至少需要 5 个有明显几何差异的有效姿态。禁止采集 10 个相同姿态。**

## 12. 运行三相机成对标定 (Stable V1)

正式标定入口:

```bash
rosrun cr5_spray_perception run_three_camera_calibration.py \
  ~/cr5_data/calibration/runs/<your_run_id>/groups \
  -o ~/cr5_data/calibration/runs/<your_run_id>/camera_extrinsics.json
```

算法流程:

```
标定靶检测 (ChArUco/ArUco/AprilTag)
  → 单相机 PnP (T_camera_target)
  → 成对相机相对变换 (T_camA_camB)
  → RANSAC 鲁棒共识筛选内点
  → 内点等权 SE(3) 平均
  → 输出 FL→FR, FL→RE 外参
```

### 标定质量检查

程序输出:

- 每组相机对的测量数 (n_total) 和内点数 (n_inliers)
- 成对变换的中位偏差 (T med) 和中位绝对偏差 (T MAD)
- 三角形闭合误差 (triangle closure)

参考:

- FL_FR / FL_RE 内点数 ≥ 3 (低于此值标定不可靠)
- T MAD 越小, 测量一致性越好

## 13. Gazebo Truth 外参验证 (可选)

仅仿真环境可用。实机不适用。

```bash
rosrun cr5_spray_perception score_gazebo_calibration.py \
  <camera_extrinsics.json> -o <truth_score.json>
```

Gazebo 稳定版 V1 工程基线:

- cam_front_right: ≤ 15mm, ≤ 1.0°
- cam_rear: ≤ 15mm, ≤ 1.0°

当前验证结果 (20 组固定姿态):

- FR: 14.78mm / 0.680° — PASS
- RE: 11.04mm / 0.816° — PASS

> 15mm / 1° 是 Gazebo 工程基线, 不代表真实 D455 精度上限或下限。
> 实机精度需在 D455 安装后独立验证。

## 14. 外参保存

通过验收的外参保存到:
```
$CR5_DATA_ROOT/calibration/accepted/
```

## 15. 历史组件

以下为研发历史遗留, 不用于 Stable V1 正式标定:

- `run_multi_frame_calibration.py` — 旧 PnP + Ceres Joint BA 流程
- `bundle_adjustment.py` — Ceres BA 求解器
- `estimate_camera_extrinsics.py` — 旧外参估计入口

Joint BA 在研发阶段已被证明会引入 camera-target 联合补偿偏差,
Stable V1 采用 pairwise camera-relative 方法替代。

## 16. 实机执行时的区别

- 每台 D455 需独立标定内参 (K) 和畸变 (D)
- 相机 topic 路径可能不同
- 标定目标需要实际制造/打印
- 深度质量受环境光照影响
- 需要更严格的安全审查
- 实机入口 `run_three_camera_calibration.py` 支持 per-camera 内参输入
