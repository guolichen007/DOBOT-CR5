1. **CORNER_REFINE_SUBPIX** (V8.8): ArUco edge scale +7.5% → 40mm PnP bias → NONE 修复

3. **Single-planar depth ambiguity** (V8.14): FL 依赖 right 单面 → 需要 right+top 非共面观测
