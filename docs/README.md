## 重要原则

1. **YAML 为几何真值来源。** `calibration_target.yaml` 是标定目标的唯一权威几何定义。
2. **文档描述当前代码真实状态。** 不写未实现的功能为"已完成"。
3. **Git 历史管理版本。** 不使用 `scene_v2.yaml` / `scene_final.yaml` 等版本后缀。
