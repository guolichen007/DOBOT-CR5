# 工程维护与发布

## 目录边界

```
源码:    ~/cr5_ros1_ws/src/       (Git 跟踪)
构建:    ~/cr5_ros1_ws/build/     (catkin_make 生成, gitignored)
开发:    ~/cr5_ros1_ws/devel/     (catkin_make 生成, gitignored)
数据:    ${CR5_DATA_ROOT}         (默认 ~/cr5_data)
Python:  ${CR5_VENV_DIR}          (默认 ~/.venvs/cr5-spray)
```

## 日常维护

```bash
# 构建
bash scripts/build.sh

# 清理编译产物 (先 dry-run)
bash scripts/clean_workspace.sh
bash scripts/clean_workspace.sh --yes

# 查看源码树
bash scripts/project_tree.sh

# 统计概览
bash scripts/workspace_stats.sh

# 仓库契约检查
bash scripts/check_repository_contract.sh
```

## 配置规则

### Canonical 配置名

使用稳定名称，不用版本后缀。

正确:
- `simulation_scene.yaml`
- `cr5_initial_pose.yaml`
- `spray_tool_mount.yaml`

错误:
- `scene_v2.yaml`, `scene_v3.yaml`
- `cr5_initial_pose_v332.yaml`
- `scene_final.yaml`, `scene_final2.yaml`

版本历史由 Git 管理，不是靠文件名。

### 本机配置

`config/local.yaml` — 包含本机串号/网络配置，**绝对不要提交**。

使用 `config/local.example.yaml` 作为模板。

## 新增 ROS Package

1. 在 `src/` 下创建标准 catkin package
2. 确保 CMakeLists.txt 和 package.xml 完整
3. `scripts/build.sh` 自动发现
4. 运行 `check_repository_contract.sh` 验证

## Git 分支策略

### 长期分支（受保护）

| 分支 | 用途 | 规则 |
|------|------|------|
| `main` | 当前完整工程封板基线 | 只接受 PR，禁止 direct push，禁止 force push，禁止删除，要求 CI，要求线性历史 |
| `stable/three-camera-calibration-v1` | 标定阶段冻结分支（只读） | 禁止开发，禁止 force push，禁止删除 |
| `stable/visible-surface-reconstruction-v1` | 重建阶段冻结分支（只读） | 禁止开发，禁止 force push，禁止删除 |

### 临时分支

| 分支模式 | 用途 | 规则 |
|----------|------|------|
| `feature/*` | 功能开发 | 从 main 创建 → PR → CI 全绿 → 合并 main → 删除 |
| `fix/*` | 缺陷修复 | 同上 |
| `chore/*` | 工程维护 | 同上 |

**临时分支规则：**
1. 必须从 `main` 创建
2. 开发完成后创建 PR
3. CI 全部通过
4. 合并到 main
5. 删除本地和远程临时分支
6. stable 分支不能作为日常开发基线

### 禁止操作

- force push main 和所有 stable/* 分支
- 直接在 main 上开发
- 未经验证合并 main
- 删除三条长期分支中的任何一条

## CI Gate

仓库使用 GitHub Actions，6 个 job：

| Job | 说明 | 依赖 |
|-----|------|------|
| repository-contract | 仓库契约检查 | 无 |
| markdown-link-check | Markdown 链接检查 | 无 |
| calibration-asset-tests | 标定资产测试 | pyyaml |
| reconstruction-quality-gate | 纯 Python 质量 Gate（不依赖 Open3D） | pyyaml |
| reconstruction-full-tests | 全部重建测试（依赖 Open3D） | numpy, open3d, scipy, opencv-python, pyyaml |
| catkin-build | ROS Noetic 构建 | ROS, catkin, gazebo |

CI 触发：
- push: main, stable/three-camera-calibration-v1, stable/visible-surface-reconstruction-v1
- pull_request: main
- workflow_dispatch: 手动触发
